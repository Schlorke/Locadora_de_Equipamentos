# 🎨 GB Locações Design System

Bem-vindo ao **Design System GB Locações** - uma coleção completa e moderna de
componentes, padrões e diretrizes para construir interfaces consistentes,
acessíveis e de alta qualidade.

---

## 📚 O que você encontrará aqui

### 🎨 Design Tokens

Valores fundamentais que definem a identidade visual do sistema:

- **Cores** - Paleta primária, secundária e semântica
- **Tipografia** - Fontes, tamanhos e hierarquia
- **Espaçamento** - Sistema consistente de spacing
- **Sombras** - Elevações e profundidade
- **Breakpoints** - Sistema responsivo mobile-first

### 🧩 Componentes Públicos

Componentes para o site público e área do cliente:

- **Atoms** - Componentes básicos (Button, Input, Badge, etc.)
- **Molecules** - Componentes compostos (Card, SearchBar, Alert, etc.)
- **Organisms** - Componentes complexos (Navigation, Form, Dialog, etc.)
- **Templates** - Layouts de página completos

### 🔐 Componentes Administrativos

Componentes específicos para o painel administrativo:

- **Layout** - Sidebar, Header e estrutura admin
- **Components** - AdminCard, SettingsBlock, etc.
- **Features** - Funcionalidades complexas (Carousel Manager, etc.)
- **Pages** - Páginas completas do admin

### 🤝 Componentes Compartilhados

Componentes usados em ambos os domínios:

- **Form** - Sistema completo de formulários (React Hook Form + Zod)
- **Data Display** - Tabelas, calendários, gráficos
- **Feedback** - Toasts, alerts, notificações

---

## 🚀 Como Usar Este Storybook

### 1. Explorar Componentes

Navegue pelo menu lateral para encontrar o componente que precisa. Cada
componente tem:

- **Canvas** - Visualização interativa
- **Docs** - Documentação completa
- **Controls** - Playground para testar props
- **Stories** - Variações e casos de uso

### 2. Testar Variações

Use o **Playground** em cada componente para experimentar diferentes combinações
de props em tempo real.

### 3. Copiar Código

Cada componente inclui exemplos de código prontos para copiar e usar no projeto.

### 4. Verificar Acessibilidade

Use a aba **Accessibility** (addon A11y) para validar se o componente atende aos
padrões WCAG 2.1 AA.

## 🎯 Princípios do Design System

### ✅ Consistência

Todos os componentes seguem os mesmos design tokens, garantindo uma aparência
uniforme em toda a aplicação.

### ♿ Acessibilidade

Componentes construídos com acessibilidade em mente:

- Navegação por teclado
- ARIA labels apropriados
- Contraste de cores adequado
- Suporte a leitores de tela

### 📱 Responsividade

Design mobile-first com breakpoints bem definidos:

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

### ⚡ Performance

Componentes otimizados para velocidade:

- Lazy loading quando apropriado
- Animações suaves (60fps)
- Bundle size otimizado

### 🧪 Testabilidade

Componentes projetados para serem facilmente testáveis:

- Props bem definidas
- Estados previsíveis
- Integração com Vitest

---

## 🛠️ Stack Tecnológico

Este design system é construído com:

- **Next.js 15** - Framework React com App Router
- **TypeScript** - Type safety e melhor DX
- **Tailwind CSS** - Utility-first CSS framework
- **Radix UI** - Componentes primitivos acessíveis
- **Framer Motion** - Animações suaves
- **Lucide React** - Ícones consistentes
- **React Hook Form** - Gerenciamento de formulários
- **Zod** - Validação de schemas
