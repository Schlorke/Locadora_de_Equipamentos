`hover-action-menu` e `grid-motion`. Cada um ganhou contrato + web + native em
`packages/ui`. Web preserva group-hover / GSAP e as classes originais
(`text-slate-700`, `hover:text-orange-600`, `bg-[#111]`, `radial-gradient`).

`category-badge` permanece em `components/ui` (acoplado a
`lib/utils/category-helpers` / regra de negócio). Consumidores atualizados para
`@gb-locacoes/ui`; legados aposentados com zero imports. Esta fatia está em
estado intermediate; a migração não está concluída.
