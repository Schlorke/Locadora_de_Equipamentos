# 267-cta

web + native). Variantes `primary` | `secondary` | `outline` | `ghost` e presets
(`QuoteCTA`, `ContactCTA`, `PhoneCTA`, `WhatsAppCTA`, etc.) permanecem. Na web,
`bg-orange-600` (marca `#ea580c`) e o verde do WhatsApp não foram trocados. O
nativo resolve estilo via tokens, sem classes Tailwind da web.

não foi migrado. O legado foi removido. Esta fatia está em estado intermediate;
a migração não está concluída.
