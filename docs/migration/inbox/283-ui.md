# 283-ui

Três primitivos sem regra de negócio saíram de `components/ui/`: `toggle`,
`toggle-group` e `resizable`. Cada um ganhou contrato + web + native em
`packages/ui`. Web preserva Radix / `react-resizable-panels` e as classes
originais (`hover:text-orange-600`, `data-[state=on]:bg-orange-50`,
`bg-border`). Native não repete Tailwind. `toggle` e `toggle-group` não tinham
imports de produto; `resizable` tinha dois consumidores em `packages/frontend`
(email e WhatsApp admin), atualizados para `@gb-locacoes/ui`. Os três legados
foram aposentados. Esta fatia está em estado intermediate; a migração não está
concluída.
