# 294-ui

Três primitivos sem regra de negócio saíram de `components/ui/`: `context-menu`,
`navigation-menu` e `filter-indicator`. Cada um ganhou contrato + web + native
em `packages/ui`. Web preserva Radix / Lucide Funnel e as classes originais
(`bg-popover`, `bg-border`, `bg-background`, `hover:text-orange-600`,
`text-orange-500`, `text-gray-500`). Native não repete Tailwind
(`Pressable`/`View`/`useTheme`). Nenhum `.ts`/`.tsx` de produto importava os
legados; os arquivos foram aposentados. Esta fatia está em estado intermediate;
a migração não está concluída.
