# 280-ui

Três primitivos sem regra de negócio saíram de `components/ui/`: `hover-card`,
`radio-group` e `slider`. Cada um ganhou contrato + web + native em
`packages/ui`. Web preserva Radix e as classes originais (`bg-popover`,
`border-primary`, `bg-secondary`/`bg-primary`). Native não repete Tailwind.
Nenhum `.ts`/`.tsx` de produto importava os legados; os arquivos foram
aposentados. Esta fatia está em estado intermediate; a migração não está
concluída.
