# AI Documentation - GB-Locacoes

This folder contains the minimal context and navigation guides for AI agents.
Use it to keep context small, accurate, and consistent across tasks.

## Quick Start

1. Read `AGENTS.md` (mandatory project workflow).
2. Read `docs/ai/boot.md` (context boot and reading order).
3. Use `docs/ai/context-map.md` to locate the right docs quickly.

## Files

- `docs/ai/boot.md` - Minimal context to start any task.
- `docs/ai/context-map.md` - Task-to-docs mapping for fast lookup.
- `docs/ai/claude-codex-handoff-2026-09-30.md` - Reconstrução da sessão Claude,
  checkpoint herdado e evidências da validação retomada pelo Codex.
- `docs/ai/context-precision-protocol.md` - Protocolo de precisao de contexto e
  reasoning.
- `docs/ai/context-capsule-template.md` - Template for a small, high-signal
  context block.
- `docs/ai/context-capsules/README.md` - Stored context capsules for new or
  multi-file tasks.
- `docs/ai/context-intake-output-checklist.md` - Intake/output checklist for
  context hygiene.
- `docs/ai/prompt-templates/README.md` - Hybrid prompt schema templates for
  common tasks.

## Update Rules

- If you add or change behavior, update the matching `docs/features/*.md`.
- If you fix a bug, update `docs/issues/known-issues.md` (and the index).
- Always update `CHANGELOG.md` with the real date from `git log`.
