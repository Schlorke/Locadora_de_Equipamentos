# 📋 Issues e Investigações - GB Locações

Este diretório contém documentação de problemas técnicos, bugs e investigações
em andamento no projeto.

## 📂 Estrutura

Cada issue deve ter:

- ✅ Descrição clara do problema
- ✅ Contexto técnico completo
- ✅ O que foi tentado
- ✅ Possíveis soluções
- ✅ Links para referências
- ✅ Status atual

## Indices Rapidos

- `docs/issues/known-issues.index.md` - Indice curto para busca rapida.
- `docs/issues/known-issues.md` - Historico completo de issues resolvidos.
